# Oxford Social — website concept

A responsive, one-page website concept for Oxford Social in Manchester. The design follows a day-to-night narrative, pairing a warm editorial brunch palette with the venue's dark interior and red neon details.

## Run locally

```bash
npm install
npm run serve
```

Open `http://127.0.0.1:4173`.

## Test

```bash
npx playwright install chromium
npm test
```

## Content note

This is an unofficial sales concept. Venue details were cross-checked against the public Oxford Social Instagram profile and current public listings on CAMRA, EatClub, UseYourLocal and Tagvenue. No testimonials, ratings or awards are fabricated. Operational details should be confirmed with the venue before production use.

Venue and menu photography is used for this private sales demonstration from the venue's public listing imagery. Confirm image usage rights before a production launch.
